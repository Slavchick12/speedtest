# speedtest.py

Замер скорости интернета: скрипт делает N последовательных запросов к файлу по URL,
скачивает его целиком и печатает объём, среднее время запроса и скорость в МБ/с (и Мбит/с).

## Требования

- Python 3.9+ (только стандартная библиотека, зависимостей нет)

## Запуск

```bash
python3 speedtest.py <URL>              # 10 запросов
python3 speedtest.py <URL> -n 5 -t 60   # 5 запросов, таймаут 60 с
python3 speedtest.py -h                 # справка
```

Пример:

```bash
python3 speedtest.py https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
```

Пример вывода (для картинки на 0.24 МБ):

```
# 1: 0.24 МБ за 0.518 с — 0.46 МБ/с
...
Успешных запросов: 10 из 10
Скачано всего:     2.38 МБ
Среднее время:     0.577 с
Скорость:          0.41 МБ/с (3.3 Мбит/с)
```

## Как считается

- Время запроса — от отправки до получения последнего байта (включая DNS, соединение, TLS).
- Скорость — всего скачано / суммарное время успешных запросов.
- Упавшие запросы печатаются в stderr и не учитываются; если не прошёл ни один — код выхода 1.

Берите файл потяжелее (десятки МБ): на маленьких файлах основное время уходит
на установку соединения, и скорость получается заниженной.

## Проблемы

**`CERTIFICATE_VERIFY_FAILED` на macOS** — у Python с python.org не установлены корневые сертификаты.
Один раз выполните:

```bash
open "/Applications/Python 3.13/Install Certificates.command"
```

(подставьте свою версию Python).
